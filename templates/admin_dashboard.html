Supabase Database Integration

AURA STUDIOS includes a production-grade schema.sql script with Row Level Security (RLS) policies and automatic dual-engine persistence.

✦ How to connect your live Supabase cloud project:
  1. Create a project on Supabase.com.
  2. Run the queries from schema.sql in the Supabase SQL Editor.
  3. Copy your SUPABASE_URL and SUPABASE_KEY (anon or service_role).
  4. Paste them into your local .env file.
  5. Restart python app.py — it automatically switches from SQLite to Supabase Cloud!
